# 📄 论文格式自动转换工具

基于**2026届论文格式模版（最终版）**的自动格式转换Web工具，可以将Word文档一键转换为符合论文格式要求的标准文档。

## ✨ 功能特性

- 🎯 **一键转换**: 上传Word文档，自动应用标准论文格式
- 📐 **精确格式**: 严格按照2026届论文格式模版要求设置
- 🎨 **美观界面**: 现代化的Web界面，操作简单直观
- 📱 **响应式设计**: 支持桌面和移动设备
- ⚡ **快速处理**: 秒级完成格式转换
- 💾 **本地处理**: 数据不上传到外部服务器，保护隐私

## 📋 格式要求

### 页面设置
- **纸张大小**: A4 (21.0 x 29.7 cm)
- **页边距**:
  - 上: 2.5 cm
  - 下: 2.5 cm
  - 左: 3.0 cm
  - 右: 3.0 cm

### 标题样式
- **一级标题**: 黑体 16pt 居中，段前段后 6pt
- **二级标题**: 宋体 14pt 加粗，首行缩进 0.99cm
- **三级标题**: 宋体 12pt 加粗，首行缩进 0.99cm

### 正文格式
- **字体**: 宋体（中文） / Times New Roman（英文）
- **字号**: 12pt
- **首行缩进**: 0.85 cm
- **行距**: 1.5倍

### 图表标题
- **字体**: 宋体
- **字号**: 10.5pt
- **对齐**: 居中
- **段后**: 6pt

## 🚀 快速开始

### 环境要求

- Python 3.7+
- pip

### 安装步骤

1. **克隆或下载项目**
```bash
cd paper-formatter
```

2. **安装依赖**
```bash
pip install -r requirements.txt
```

3. **运行应用**
```bash
python app.py
```

4. **访问应用**

在浏览器中打开: `http://localhost:5000`

## 📖 使用说明

### 方法一: 点击上传
1. 点击上传区域
2. 选择要转换的 `.docx` 文件
3. 点击"开始转换"按钮
4. 等待转换完成
5. 点击"下载转换后的文件"

### 方法二: 拖拽上传
1. 直接将 `.docx` 文件拖拽到上传区域
2. 点击"开始转换"按钮
3. 等待转换完成
4. 点击"下载转换后的文件"

## 🔧 技术栈

- **后端**: Flask (Python)
- **前端**: HTML5 + CSS3 + JavaScript
- **文档处理**: python-docx
- **界面设计**: 现代渐变色 + 响应式布局

## ⚠️ 注意事项

1. **文件格式**: 仅支持 `.docx` 格式（Word 2007及以上版本）
2. **文件大小**: 最大支持 10MB
3. **内容保留**: 转换只修改格式，不会改变文档内容
4. **复杂格式**: 对于包含复杂图形、公式的文档，可能需要手动微调
5. **备份建议**: 转换前建议备份原文件

## 🐛 常见问题

### 转换失败怎么办？
- 确保文件是 `.docx` 格式
- 检查文件是否损坏
- 确保文件大小不超过 10MB
- 尝试用Word重新保存文件

### 格式不完全符合？
- 部分特殊格式需要手动调整
- 检查是否使用了非标准样式
- 建议使用标准Word样式

### 如何部署到服务器？
```bash
# 使用gunicorn部署
pip install gunicorn
gunicorn -w 4 -b 0.0.0.0:5000 app:app
```
